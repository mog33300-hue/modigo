Overview

This package will install the OpenCore Legacy Patcher application (v2.4.1) on your system.

Additionally, a shortcut for OpenCore Legacy Patcher will be added in the '/Applications' folder.

This package will not 'Build and Install OpenCore' or install any 'Root Patches' on your machine. If required, you can run OpenCore Legacy Patcher to install any patches you may need.

For more information on OpenCore Legacy Patcher usage, see our documentation and GitHub repository.

Files Installed

Installation of this package will add the following files to your system:

  • /Library/Application Support/Dortania/OpenCore-Patcher.app

  • /Library/PrivilegedHelperTools/com.dortania.opencore-legacy-patcher.privileged-helper
